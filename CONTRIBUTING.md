# Guía de Contribución

Gracias por tu interés en contribuir a Windows Boot Repair MCP. Este documento proporciona directrices y pasos para contribuir al proyecto.

## Código de Conducta

Al participar en este proyecto, aceptas mantener un comportamiento respetuoso y profesional.

## Proceso de Contribución

1. **Fork del repositorio**: Crea un fork del repositorio en tu cuenta de GitHub.
2. **Clonar el repositorio**: Clona tu fork en tu máquina local.
   ```bash
   git clone https://github.com/drhiidden/WindowsBootRepairMCP
   cd WindowsBootRepairMCP
   ```
3. **Crear una rama**: Crea una rama para tu feature o corrección.
   ```bash
   git checkout -b feature/nombre-de-tu-feature
   ```
4. **Realizar cambios**: Realiza tus cambios en el código.
5. **Probar cambios**: Asegúrate de que tus cambios funcionen correctamente y no introduzcan errores.
6. **Commit de cambios**: Realiza commit de tus cambios con mensajes descriptivos.
   ```bash
   git commit -m "Descripción clara y concisa de los cambios"
   ```
7. **Push a tu fork**: Sube tus cambios a tu fork en GitHub.
   ```bash
   git push origin feature/nombre-de-tu-feature
   ```
8. **Crear Pull Request**: Crea un Pull Request desde tu fork al repositorio principal.

## Estándares de Código

- **Estilo de código**: Sigue las convenciones de estilo de PowerShell.
- **Comentarios**: Incluye comentarios claros y descriptivos en el código.
- **Documentación**: Actualiza la documentación cuando sea necesario.
- **Pruebas**: Asegúrate de que tu código pase todas las pruebas.

## Reportar Problemas

Si encuentras un problema o tienes una sugerencia, por favor crea un issue en el repositorio de GitHub.

## Preguntas

Si tienes preguntas, por favor crea un issue en el repositorio de GitHub o contacta a los mantenedores del proyecto.

¡Gracias por contribuir a Windows Boot Repair MCP!
