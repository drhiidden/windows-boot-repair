## Reportar una Vulnerabilidad

Agradecemos los reportes de vulnerabilidades de seguridad. Por favor, envía un correo electrónico con los detalles de la vulnerabilidad.

### Proceso de Reporte

1. **No hagas público el problema** hasta que se haya resuelto.
2. Proporciona información detallada sobre la vulnerabilidad, incluyendo:
   - Descripción del problema
   - Pasos para reproducir
   - Posible impacto
   - Sugerencias para mitigar (si las hay)
3. Espera nuestra respuesta. Intentaremos responder dentro de las 48 horas.
4. Trabajaremos contigo para resolver el problema y publicar una actualización.

## Medidas de Seguridad Implementadas

- **Confirmación de ejecución**: El programa requiere confirmación explícita para ejecutar cambios reales.
- **Modo simulación**: Permite probar la herramienta sin realizar cambios reales.
- **Backup automático**: Crea copias de seguridad antes de realizar cambios.
- **Verificación de entorno**: Comprueba el entorno antes de ejecutar operaciones críticas.
- **Logging detallado**: Registra todas las operaciones para facilitar la auditoría.

## Mejores Prácticas de Seguridad

- Siempre ejecuta la herramienta con privilegios de administrador.
- Utiliza el modo simulación para pruebas iniciales.
- Crea backups manuales adicionales antes de ejecutar cambios reales.
- Revisa los logs y reportes para identificar posibles problemas.
- Mantén el sistema y las herramientas actualizadas.
